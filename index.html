우리집 서랍 개인정보처리방침

시행일: 2026년 10월 27일

요약: 우리집 서랍은 회원가입이 없고, 사용자가 입력한 정보를 서버로 보내거나 수집하지 않습니다. 모든 정보는 사용자의 기기 안에만 저장됩니다. (바코드로 상품 이름을 찾을 때 바코드 번호만, 내일 날씨를 볼 때 도시나 대략적인 위치만 외부 서비스에 조회합니다.)

1. 수집하는 개인정보

우리집 서랍(이하 ‘앱’)은 이름, 이메일, 전화번호, 위치, 기기 식별자 등 어떤 개인정보도 수집하지 않습니다. 회원가입과 로그인 기능이 없습니다.

2. 기기 안에 저장되는 정보

앱을 쓰면서 사용자가 직접 입력한 아래 정보는 사용자 기기의 앱 저장 공간에만 저장되며, 개발자나 제3자에게 전송되지 않습니다.

  • 물건 정보: 이름, 수량, 유통기한, 보관 위치, 메모, 구매일, 구매가 등
  • 사용자가 올린 사진: 물건 사진, 영수증·보증서 사진, 레시피 사진
  • 레시피 관련 기록: 직접 등록한 레시피, 즐겨찾기, 식단, 요리 기록, 장보기 목록, 메모
  • 위시리스트, 정기 관리 알림, 빌려준 물건 기록(빌려준 사람 이름 포함), 다 먹은·버린 음식 기록, 정리한 옷 기록, 바코드와 상품 이름, 앱 설정

앱을 삭제하면 이 정보도 함께 삭제됩니다. 사용자는 앱의 ‘설정 → 정리하기’에서 언제든지 모든 정보를 지울 수 있습니다.

3. 기기 권한

  • 카메라·사진: 물건·영수증·레시피 사진을 올리거나 바코드를 찍을 때만 사용하며, 사진은 기기 안에만 저장됩니다. 바코드는 Google Play 서비스의 코드 스캐너가 기기 안에서 읽습니다.
  • 대략적인 위치: 코디 추천에서 ‘현재 위치’ 날씨를 누를 때만 사용합니다. 도시를 직접 고르면 위치 권한 없이 쓸 수 있습니다.
  • 알림: 유통기한 임박, 재고 부족, 정기 관리 알림을 보내기 위해 사용하며, 알림은 기기 안에서 만들어집니다.

권한은 거부해도 앱의 나머지 기능을 쓸 수 있습니다.

4. 외부 서비스로 이동

‘쿠팡에서 사기’ 같은 버튼을 누르면 외부 쇼핑 사이트나 앱으로 이동합니다. 이때 검색어(재료나 물건 이름)만 외부 사이트로 전달되며, 그 이후의 정보 처리는 해당 서비스의 개인정보처리방침을 따릅니다.

바코드를 찍었는데 이 기기에 기억된 상품 이름이 없으면, 상품 이름을 찾기 위해 바코드 번호만 공개 상품 데이터베이스 Open Food Facts(openfoodfacts.org)에 조회합니다. 사용자의 다른 정보는 함께 보내지 않습니다.

코디 추천에서 내일 날씨를 불러올 때는, 사용자가 고른 도시의 좌표나 ‘현재 위치’를 눌렀을 때의 대략적인 좌표(소수 둘째 자리까지, 약 1km 단위)만 무료 날씨 서비스 Open-Meteo(open-meteo.com)에 보냅니다. 위치는 날씨를 받는 데만 쓰고 따로 저장하거나 다른 곳에 보내지 않습니다.

앱의 글꼴을 표시하기 위해 처음 실행할 때 Google Fonts에서 글꼴 파일을 받아올 수 있습니다. 이 과정에서 사용자가 입력한 정보는 전송되지 않습니다.

5. 백업과 내보내기

‘백업 파일 만들기’, ‘백업 코드 만들기’, ‘전체 목록 내보내기’는 사용자가 직접 실행할 때만 동작하며, 만들어진 내용은 사용자가 원하는 곳에 직접 붙여넣거나 저장합니다. 앱이 자동으로 어딘가로 보내지 않습니다.

6. 아동의 개인정보

앱은 개인정보를 수집하지 않으므로 만 14세 미만 아동의 개인정보도 수집하지 않습니다.
